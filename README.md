## 📌 About the Project

An AI-powered computer vision system that detects and tracks people in video streams using **YOLOv8 and DeepSORT**.

The system assigns unique tracking IDs to individuals, monitors their movement within predefined polygonal zones, identifies inside/outside zone status, and displays real-time occupancy counts.

## ✨ Key Features

- 🎯 **Human Detection** – Detects people using YOLOv8.
- 🔍 **Multi-Object Tracking** – Tracks multiple individuals using DeepSORT.
- 🆔 **Unique Tracking IDs** – Maintains individual identities across video frames.
- 📍 **Zone Monitoring** – Identifies people inside and outside predefined polygonal zones.
- 👥 **Occupancy Counting** – Displays the current number of tracked people inside the zone.
- 🎥 **Real-Time Visualization** – Displays bounding boxes, tracking IDs, zone status, and occupancy count.
